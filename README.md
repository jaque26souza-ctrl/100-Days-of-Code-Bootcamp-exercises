# 🐍 100 Days of Code: The Complete Python Pro Bootcamp

Bem-vindo ao meu repositório de acompanhamento do curso **100 Days of Code™: The Complete Python Pro Bootcamp** (da instrutora Angela Yu). Este espaço serve para documentar meu progresso diário, projetos desenvolvidos e conceitos aprendidos ao longo da jornada de 100 dias.

---

## 🎯 Sobre o Desafio

O objetivo principal é construir a consistência na programação, desenvolvendo **100 projetos em 100 dias**, cobrindo áreas como:
* Lógica de Programação e Estruturas de Dados
* Automação e Scripting
* Desenvolvimento de Jogos e Interfaces Gráficas (GUI)
* Ciência de Dados e Análise de Dados
* Desenvolvimento Web e APIs

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Python 3
* **Ambientes:** PyCharm, VS Code, Jupyter Notebook
* **Tópicos:** OOP, Pandas, NumPy, Flask, Tkinter, Selenium, Beautiful Soup, APIs, etc.
